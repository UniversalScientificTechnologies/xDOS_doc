# Data management

DOSPORTAL makes data management easy. Data can not only be sorted and filtered, but on top of that DOSPORTAL introduces calendar views.

## Filtering

The displayed data can be narrowed down by the type of data, by the detector that recorded it and other parameters.

## Calendar views

Users can display data laid out on a time axis, which keeps a large amount of measurements organised and easy to navigate.

The same data can be displayed as a month, week, list or year view, so both a long campaign and a single day can be inspected at the same place.
